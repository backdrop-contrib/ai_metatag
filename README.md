# AI Metatag

Draft titles, descriptions, and social sharing metadata from a page’s content. Review suggestions on the edit form or let the module fill empty tags when editors save.

## Requirements

Backdrop CMS 1.x, PHP 8.2 or later, and AI and Metatag. Configure a chat model for generation. AI Async is optional for background generation.

## Installation

1. Install and enable the module using the official [Backdrop CMS instructions](https://backdropcms.org/user-guide/modules).
2. Open **AI Metatag Assistant** at `admin/config/ai/ai-metatag` and enable the desired content types.

See the [module wiki](https://github.com/backdrop-contrib/ai_metatag/wiki) for setup, use, and troubleshooting.
